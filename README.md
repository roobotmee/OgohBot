### 📱 Admin Ogohlantirgich Bot

## 🤖 Bot haqida

Bu Telegram bot guruh adminlarini tez va oson ogohlantirish uchun yaratilgan. Guruh a'zolari "@admins" deb yozganda, bot barcha adminlarni bir vaqtda mention qiladi va ularni xabardor qiladi.

## ✨ Asosiy imkoniyatlar

- 🔔 **Admin ogohlantirish**: Guruhda "@admins" deb yozilganda, barcha adminlarni mention qiladi
- 👋 **Yangi a'zolarni kutib olish**: Guruhga yangi a'zo qo'shilganda, qoidalar va ma'lumotlar bilan salomlaydi
- 🔗 **Guruhga qo'shilish**: /start buyrug'i orqali guruhga qo'shilish uchun havola beradi


## 🛠️ O'rnatish

1. [@BotFather](https://t.me/BotFather) orqali yangi bot yarating va token oling
2. Kodni yuklab oling
3. `$token = "tokkkkkeeeeeeennnnnnn";` qatoridagi "tokkkkkeeeeeeennnnnnn" o'rniga o'z botingiz tokenini yozing
4. `'url' => "https://t.me/gruuppalinki"` qatoridagi "gruuppalinki" o'rniga o'z guruhingiz havolasini yozing
5. Kodni serverga joylang va webhook sozlang
